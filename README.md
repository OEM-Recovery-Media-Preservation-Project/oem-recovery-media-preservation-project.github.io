# oem-recovery-media-preservation-project.github.io
This is a preservation project for OEM Recovery Media! This website is a repository leading to all sorts of recovery media for OEM computers.

Note, this repository is still in progress! I find and add models all the time to this list. It's going to take a long time to do all of them, but still.

If you would like to contribute, contact us at anonymoustestuser0000@gmail.com with your link to your uploaded recovery media, as well as the model and any information.
